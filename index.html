Povezivanje sa Supabase bazom

Trajno spremanje klupica i slika u oblaku

Kako doći do ovih podataka (2 minute):

  1. Otvorite besplatni račun na supabase.com
  2. Kreirajte novi projekt (nazovite ga npr. klupice)
  3. Otvorite SQL Editor i zalijepite sadržaj datoteke supabase_schema.sql te kliknite Run
  4. U Project Settings -> API kopirajte Project URL i anon public API ključ.
